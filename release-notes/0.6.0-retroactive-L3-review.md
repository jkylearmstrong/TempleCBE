## Findings

1. The 0.6.0 release notes described features from 0.5.9 to 0.5.12 as new. Corrected in 0.6.1 NEWS.
2. Deprecated wrappers promised for removal in 0.6.0 were not removed. Re-scheduled to 0.7.0 in 0.6.1.
3. The package version was part of every checkpoint fingerprint, so any release invalidated users' caches. Replaced by `checkpoint_schema_version()` in 0.6.1.
4. A version-pinned test would have failed on the next bump. Replaced by a version-agnostic test in 0.6.1.
5. A legacy-data reference in `as_tuning_results()` documentation was removed (public-repo anonymization policy).

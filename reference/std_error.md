# Compute standard error

Compute standard error

## Usage

``` r
std_error(x, na.rm = FALSE)
```

## Arguments

- x:

  vector of data

- na.rm:

  should NA values be removed, TRUE or FALSE, default is FALSE

## Value

numeric value representing standard error

## Examples

``` r
std_error(mtcars$mpg)
#> [1] 1.065424
```

# Format Hazard Ratio and Confidence Interval

Format Hazard Ratio and Confidence Interval

## Usage

``` r
fmt_hr(hr, conf_low, conf_high, digits = 2)
```

## Arguments

- hr:

  Point estimate for Hazard Ratio

- conf_low:

  Lower 95% confidence limit

- conf_high:

  Upper 95% confidence limit

- digits:

  Number of decimal places (default: 2)

## Value

Formatted string (e.g., "HR 1.25 (95% CI 1.05–1.48)")

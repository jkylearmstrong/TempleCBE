# Path to the Ready-Made Quarto Reproducibility Appendix Child Template

Returns the file path to the packaged \`repro_appendix.qmd\` child
document so Quarto and R Markdown reports can include it directly via
\`knitr::knit_child(repro_appendix_template(), quiet = TRUE)\`.

## Usage

``` r
repro_appendix_template()
```

## Value

Character file path to \`inst/templates/repro_appendix.qmd\`.

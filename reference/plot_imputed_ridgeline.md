# Ridgeline Density Comparison of Original vs Imputed Distributions

Displays overlapping density ridgelines comparing observed versus
imputed distributions.

## Usage

``` r
plot_imputed_ridgeline(orig, imp, cols)
```

## Arguments

- orig:

  Data frame containing original (pre-imputation) values.

- imp:

  Data frame containing post-imputation values.

- cols:

  Character vector of variable names to compare.

## Value

A \`ggplot2\` object.

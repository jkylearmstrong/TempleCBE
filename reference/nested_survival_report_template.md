# Packaged Nested Survival Report Quarto Child Template

Locates and returns the file path to the packaged Quarto child report
template (\`nested_survival_report.qmd\`) used by \[domain_children()\]
to render a complete nested survival analysis report for a domain run
object.

## Usage

``` r
nested_survival_report_template()
```

## Value

File path character string.

## See also

\[domain_children()\], \[nested_survival_run()\]
